## 01.ルーティングと認証の突破

- **`<Link>` と `<a>` の違い**: `Login.tsx` に `<Link to="/signup">Linkで移動</Link>` と `<a href="/signup">aで移動</a>` を並べて置こう。DevTools の Network タブを開いたまま、それぞれクリックする。リクエストの出方はどう違う？ 画面の切り替わり方は？ React のアプリで `<Link>` を使うのはなぜ？
- **`replace` の役割**: `App.tsx` の `<Navigate to="/login" replace />` について。(a) `/todos` を開く → アドレスバーに `/abc` と打って移動 → ブラウザの「戻る」を1回押す。どこに戻る？ (b) `replace` を消して同じ操作をすると、どうなる？ `replace` は履歴に対して何をしている？
- **誰が `/login` を返しているのか**: Go のサーバーを起動して `http://localhost:8080/login` を開くと、どうなる？ `http://localhost:3000/login` は表示できるのに、なぜ違う？ `main.go` の `appMux.Handle("/", ...)` と、Network タブで `localhost:3000/login` が返している中身（Response）を見比べて考えよう。
